From 23 Manual Steps to 10 Seconds

Automating a daily news-monitoring report for the mobile handset industry — transforming a repetitive 26-column export into a consistent 13-column client report with one macro run.

The Challenge

A daily report had to be rebuilt manually from a system export. Most of the work was repetitive, time-consuming, and prone to avoidable counting mistakes.

What the manual process involved

  • Deleting 18 unnecessary columns and rebuilding the report layout.
  • Shortening company names and standardizing National / Local media as Print.
  • Copying hyperlinks from news titles one by one.
  • Entering coverage weeks and counting news by company and Print / Online group.
  • Moving a priority brand to the top, then formatting the report.

The required output

A standardized 13-column client report containing Company, Phone Model, Category, Global/Local, Coverage Week, Date, Print/Online, News Quantity, Media Name, Tier, Key Topic, News Title, and Link. Fields not supplied by the source were intentionally left blank to match the client template.

The Solution

An Excel VBA macro orchestrates the complete reporting workflow, combining worksheet formulas, helper columns, sorting, hyperlink extraction, and validation.

Prepare

Detect the used range, create an Excel Table, and apply borders.

Remove columns

Delete 18 unneeded fields from the 26-column export.

Extract links

Use the GetURL helper function to retrieve each hyperlink address.

Standardize

Sort records, map National / Local to Print, and shorten company names.

Prioritize

Use a flag and sequence number to move the priority brand first.

Build layout

Rename, add, and reorder fields; calculate the coverage week from date.

Count news

Count each company and Print / Online group; write the total once per group.

Format & check

Apply report formatting and a count reconciliation rule.

Macro execution

The main procedure, Mobile_Handset_Report, is stored in PERSONAL.XLSB and launched from Excel's Macro dialog using Alt+F8.

VBA implementation

The separate GetURL(rng As Range) helper checks the cell's Hyperlinks collection and returns the hyperlink address, or an empty string if no hyperlink is available or an error occurs.

Quality Control

A built-in conditional-formatting rule flags a mismatch between the sum of News Quantity and the number of populated Print / Online rows.

=SUM(H:H)<>COUNTA(G:G)-1

Validation limitation: this check confirms that overall totals reconcile, but it does not independently prove that each Company × Print / Online group has the correct count. A spot-check of one or two groups remains advisable.

Measured Results

Three recorded timing comparisons show that the macro completed in under 10 seconds across the tested file sizes.

Across all three tests combined, processing time fell by 99.11%: 50 minutes 10.2 seconds of manual work compared with 26.9 seconds of macro execution. The three-test average macro run time was 8.97 seconds.

Before

23 manual steps, repeated cleanup and formatting, manually copied links, and news counts typed by hand.

After

One macro run builds the client-ready layout, extracts links, calculates counts, formats the report, and applies an overall count check.

Development & Skills

Independently developed over three days through practical problem-solving and workflow design.

Problem-solving approach

A major part of the work was identifying formulas that could complete an entire field, deciding where supporting columns were needed, and arranging the operations so the process could run end to end without manual intervention.

Tools and techniques

Microsoft Excel LTSC Professional Plus 2024, VBA, PERSONAL.XLSB, Excel Tables, structured-reference formulas, date logic using EOMONTH, sorting, helper columns, dictionary-based counting, hyperlink extraction, and conditional formatting.
